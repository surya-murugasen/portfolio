# Surya M - Software Developer Portfolio

A modern, responsive, and premium dark-themed personal portfolio website for Surya M, a Software Developer skilled in React, Java, Flutter, and Full Stack Web Development.

## 🚀 How to Run the Project

Since this project is built using vanilla HTML, CSS, and JavaScript, there are no dependencies to install or complex build steps required.

**Option 1: The Easiest Way (Direct Open)**
1. Navigate to the project folder on your computer.
2. Double-click on the `index.html` file.
3. It will open directly in your default web browser.

**Option 2: Using VS Code (Recommended for Live Updates)**
1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey) if you haven't already.
3. Right-click on `index.html` and select **"Open with Live Server"**.
4. A local development server will start, and the portfolio will open in your browser. Any changes you make to the code will automatically refresh the page!

## ✨ Features

- **Premium Dark Theme**: Sleek enterprise-style dark mode with subtle Electric Blue and Amethyst Purple gradient accents.
- **Glassmorphism Design**: Modern, semi-transparent frosted glass effects on cards and sections.
- **Fully Responsive**: Flawless layout across Desktop, Laptop, Tablet, and Mobile devices with touch-friendly navigation.
- **Micro-Animations**: Smooth scroll reveal effects using the Intersection Observer API for an engaging user experience.
- **Semantic & Accessible**: Clean HTML structure prioritizing readability and SEO.

## 🛠️ Technologies Used

- **HTML5**: Semantic layout and structure.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, media queries, and animations.
- **JavaScript (Vanilla)**: DOM manipulation, mobile hamburger menu toggle, and scroll-triggered animations.
